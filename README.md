# LaTeX Resume

A professional, ATS-friendly Resume built with LaTeX, featuring a clean layout and structured sections for technical job applications.

## Features

- Clean and professional Resume layout
- ATS-friendly, machine-readable PDF output
- Organized education, skills, projects, certifications, and achievements sections
- Clickable email, phone, GitHub, and LinkedIn links
- Easily customizable LaTeX source code

## Built With

- **LaTeX** — Resume formatting and document generation
- **Hyperref** — Clickable links
- **Tabularx** — Structured alignment and layout

## Project Structure

```text
Resume-latex/
├── Resume.tex
├── Resume.pdf
└── README.md
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/RupeshNipanikar/Resume-Template)
   ```

2. Open `Resume.tex` using [Overleaf](https://www.overleaf.com/) or a local LaTeX editor.
3. Update the Resume content, including education, technical skills, projects, and certifications.
4. Compile the `.tex` file to generate the PDF.

## Customization

You can customize the Resume by editing the LaTeX source to update:

- Personal and contact information
- Education and academic achievements
- Technical skills and tools
- Projects and work experience
- Certifications and extracurricular activities

## Preview

Compile `Resume.tex` to view the latest version of the Resume as a PDF.
